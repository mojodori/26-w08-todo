## Bootstrap vs Tailwind

화면
- bootstrap: 흰 배경에 기본 파란 버튼, 빨간 테두리 삭제 버튼. 기능은 다 되지만 기본 템플릿 느낌
- tailwind: 카드형 배경, 둥근 모서리, 보라 계열 색. 처음부터 더 정돈된 화면

코드 (추가 버튼 class)
- bootstrap: `class="btn btn-primary"`
- tailwind: `class="min-h-11 shrink-0 rounded-lg bg-indigo-600 px-4 text-sm font-semibold text-white ..."`
- bootstrap은 `btn-primary` 하나에 색, 여백, 둥글기가 이미 들어 있는 완성된 부품
- tailwind는 색(`bg-indigo-600`), 여백(`px-4`), 둥글기(`rounded-lg`), 높이(`min-h-11`)를 작은 조각으로 하나씩 조합
- tailwind는 class가 길지만, PRD의 44px 터치 영역 같은 요구사항을 class에서 바로 확인 가능

구현 계획
- 같은 PRD, 같은 프롬프트였는데 tailwind 쪽 계획이 처음부터 더 꼼꼼했음 (전체 0개 문구 우선순위, randomUUID, 진행률 0.3초 전환 등이 이미 포함)
- 프레임워크 차이보다는 AI 답변이 매번 조금씩 달라지는 영향으로 봄

최종 선택: tailwind
- 두 버전 모두 주요 완료 기준 충족
- 디자인 완성도가 더 높았고, 이후 디자인을 바꿀 때 class만 바꾸면 돼서 보완 작업이 편함
